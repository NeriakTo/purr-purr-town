## 五、實作過程中自行發現並修掉的缺陷

`useDialogChrome` 原本讓 Esc 的 effect 依賴 `onClose`。呼叫端普遍傳行內箭頭函式，父元件每次重繪都會產生新引用，effect 隨之解除再註冊，該彈窗的 token 會重新排到堆疊尾端。若重繪的是底層彈窗，它會被誤判為最上層，一次 Esc 就關錯視窗。改為把行為存進 ref、effect 僅在掛載時註冊一次，堆疊順序才等於實際開啟順序。同時讓「最上層但不接受 Esc」的阻斷式視窗吞掉事件，避免 Esc 穿透去關底下的視窗。修正後重跑巢狀 Esc 測試，行為正確。
