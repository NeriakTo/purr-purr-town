| 檔案 | 內容 |
|---|---|
| `01-操作規格-v0.4-總則.md` | 一次性編號、收據、送出端待送清單、錯誤碼 |

| `03-操作規格-v0.4-連線讀取與未決.md` | 斷線與多裝置、GAS 轉送、讀取端點、規則版本、待驗證的規則與驗證方式 |

- 兩個模型的審查原文與逐項處置表沒有收進倉庫。檔頭 `related` 列的處置表與規劃文件也在知識庫，不在倉庫。
